# CMZ · BO7 Zombies EE AIO

**Comfy Munchie Zombies** companion app for Black Ops 7 Zombies — Main EE step tracking and code tools for every map through Season 4.

## Live web app

https://downdog2519.github.io/bo7-zombies-ee-aio/

## Desktop (Electron)

```bash
npm install
npm start
```

## Maps

- Ashes of the Damned
- Astra Malorum
- Paradox Junction
- Totenreich
- Kowakujō

Progress and code inputs save in your browser (`localStorage`).
