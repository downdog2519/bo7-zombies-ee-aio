Main menu: pick a map. Progress % shows completed Main EE steps.

EE Steps: select a step, follow bullets, tick ✔ when done — auto-advances and saves.

Code tools (cheat sheets): interactive sheets to type / select / tick run-specific codes so you don’t hunt them in EE text — same idea as Astra’s Code Tracker, Paradox Notes/Piano, Ashes Ingredients/Rocket Code.

Per map: Ashes Ingredients + Rocket Code · Astra Code Tracker · Paradox Notes Map + Piano · Totenreich / Kowakujō Code Tracker.

Progress uses localStorage (persists between app launches).

  • Each map has its own completed-step list and code-tool inputs.
  • Use RESET EE PROGRESS on a map to clear that map’s steps only.
  • Returning from linked code tools restores your last active EE step.
